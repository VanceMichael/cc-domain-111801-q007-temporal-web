# TemporalWeb 来源约定

此服务管理历史观察协商、时点引用解释及订单历史包接收。
当前常规业务使用一个选定来源上下文处理直接列出的记录。目录请求为 `GET /web/current`，返回 `site` 与 `pages`。每个目录成员以 `id`、`href` 提供来源身份与原文位置，原文中的 `page` 和 `site` 必须与目录一致。
## 记录含义

```json
{
  "page": "PAGE1",
  "site": "shop-a",
  "url": "https://shop.invalid/terms",
  "observedAt": "2026-11-01T09:00:00Z",
  "title": "运输说明",
  "body": "本地区运费以订单确认页为准"
}
```

这里的字段是来源提供的原始声明，数值文本必须符合十进制规则，不能把空白或未知值转换成零。领域解释保留站点页面身份、实际观察时间、同观察内容冲突。只有所选范围内且有充分常规依据的记录列入当前收件；其他范围、待确认、历史和冲突分别保留结果，不用覆盖旧原文消除分歧。

## 本地合作源

`fixtures/source.json` 的 `resources` 是本地来源的 URL 路径到响应正文的映射；只绑定回环地址，不连接真实监管、银行或合作方。原文可通过目录声明的位置取得。同一来源也可发布关联资料，当前示例的关联资料位置为 `/web/current/relations/PAGE1`，字段保留来源的业务含义：

```json
{
  "period": [
    "2026-10-01",
    "2026-11-01"
  ],
  "archive": "/archive/timegate",
  "references": [
    {
      "page": "zones",
      "edition": "v4"
    }
  ]
}
```

`fixtureSource` 支持独立实例、指定路径返回码、一次性来源故障、响应延迟与 `replace` 更新资源；访问记录保留实际请求路径，不凭空生成未收到的响应。测试在进程内操作夹具，不提供对外开放的管理接口。目录不承诺所有关联资料与当前目录同时发布；HTTP 404、403、503 不能自行解释为业务删除。

## 原文和收件

原文字节按 SHA-256 寻址，SQLite 保存来源位置、观察时间、收件范围、业务身份、领域记录与决策。收到原文不等于领域接收成功；重复的同一内容不新增收据，同一身份的不同内容不会覆盖原件。`.data/` 仅用于本机数据，演示使用临时目录，运行结束关闭服务并清理临时状态。

## 历史协商

关联资料中的 `archive`（或 `archives`）声明合作归档站的协商入口路径，必须是同源路径。历史采集只通过协商入口取得历史资料，不读取当前正文或当前附表代替历史资料；关联资料中的当前引用仅用于发现入口，不作为历史订单的引用依据。

协商请求有两种：

- `GET {archive}?page={页面}&at={订单时点}`：请求订单时点的正文观察。
- `GET {archive}?page={页面}&edition={版本}`：按正文明确引用的版本请求附表，不得以时间更近的不同版替换。

正文观察响应声明以下字段：

- `source`：归档来源身份，历史包与查询如实回显。
- `observedAt`：归档实际采样时间。禁止用协商请求时间冒充页面真实发布时间。
- `period`：该观察所属的站点发布周期，左闭右开。允许使用的资料时段由订单所属站点的发布周期决定：订单时点与观察时间都必须落在周期内，归档返回周期外的观察不被采纳，只找日期最接近的正文不构成历史依据。
- `record` 与 `references`：正文原文及其明确引用的附表版本。正文与附表可能属于不同采样时刻，各自的时间分别记录。
- `withheld`：同一周期内归档已知但只肯返回较近一版的其他版本。只能记为已取得线索但未取得原文，不得据此声称另一版不存在。

HTTP 404 表示归档明确答复周期内无观察或所引版本缺档；其他失败（含重定向、暂不可用）属于协商未完成，不能解释为业务删除或当时没有该条款。站点迁移后同一历史网址可能转向新品牌页面，当前重定向不构成历史身份依据，客户端不跟随重定向。

## 历史包

每次按订单采集形成一个历史包，状态为：

- `complete`：正文观察与引用附表齐备，时间与引用关系均可说明。
- `content-no-observation`：订单时点未落入任何已归档发布周期，正文无合适观察。
- `annex-missing`：正文明确引用的附表版本在所有声明归档源均未取得。
- `source-conflict`：不同归档来源对同一观察时刻或同一附表版本给出不同内容。
- `negotiation-failed`：协商未完成，当时条款状态未知。

包内每个正文观察与附表分别记录 `observedAt`（归档采样时间）、`acquiredAt`（实际取得时间）与 `source`（归档来源）；包本身记录 `assembledAt`（成包时间）。问题列入 `issues`，保留版本与未协商成功的来源列入 `caveats`。历史包按（范围、订单、摘要）保存收据：协商失败只新增失败包，不覆盖既有历史原文与收据，也不回退写入当前页。`historicalReport` 按订单返回全部历史包，供资料人员复查时间与引用关系。
